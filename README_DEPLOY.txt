ديوان أبو البسم — إصدار سحابي مستقل

1. ارفع ملفات هذا المجلد في مستودع GitHub جديد (لا تستخدم مستودع الشبة).
2. Render > New Web Service > اربط المستودع الجديد.
3. Build Command: npm install
4. Start Command: npm start
5. افتح /streamer.html للتحكم، واربط Twitch وTikTok وKick من نفس الصفحة (تفاصيل Kick في KICK_SETUP_AR.txt).
6. انسخ رابط OBS من لوحة الستريمر وضعه Browser Source في OBS.
7. المشاركة: !انضم ثم 1 أو 2 أو 3 أو 4. أول إجابة فقط لكل شخص في الجولة.

ملاحظات: اتصال TikTok يعتمد على tiktok-live-connector غير الرسمي وقد يفشل عند تغيير TikTok لواجهاته أو عند عدم وجود بث مباشر. اتصال Twitch مجهول وتجريبي. البيانات محفوظة في ذاكرة خادم Render فقط وقد تضيع عند إعادة التشغيل؛ لا تشارك رابط لوحة الستريمر. لا تنشر رموز الجلسة.

خصوصية الجلسات: فتح لوحة الستريمر في تبويب جديد يبدأ بمسابقة نظيفة بلا رسائل أو نقاط قديمة. تحديث نفس التبويب يبقي رابط الغرفة مؤقتاً، لكن لا يستعيد تاريخ المتصفح. رابط viewer.html وحده يعرض شاشة انتظار فارغة؛ رابط OBS المخصص للغرفة يعرض الجولة الجارية. لا تُعرض رسائل الشات القديمة عند أول اتصال بمشاهدة الغرفة، وتظهر الرسائل الجديدة فقط بعد الاتصال.
